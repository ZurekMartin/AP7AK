# AP7AK
Desktop application for generating and analysing random data

## Functionality
- Graphical desktop UI for generating random values (hardware and software modes)
- Support for multiple data types: int, float, double, bytes, string, bits
- Numeric scaling and range limits, including unsigned integers
- Configurable string length and character sets (lower/upper/digits/special)
- Continuous and batch generation with live device monitoring
- Export generated data to files and copy to clipboard
- Seed collection from user events and SHA3-512 seeding for software mode
- Entropy and compression analysis per generated dataset
- Persistent statistics stored as JSON with HW vs SW comparison
